# Beta sign-in progress

The timetable now shows flowing water while it restores a session, checks access and opens the timetable. Email and SMS sign-in use the same indicator. The water stops when the user needs to enter a code or respond to an error. Reduced-motion users see a static bar and the current step.

The login gate reports an authentication library loading failure. Optional panels wait for their dependencies, and the Information Center offers a retry if a response is incomplete.

The five protected frontend files are index.html, timetable.js, timetable.css, information-center.js and availability-lookup.js. The final product commit is d82cf6d21d29b48b555e70821916ae38bae64940.
