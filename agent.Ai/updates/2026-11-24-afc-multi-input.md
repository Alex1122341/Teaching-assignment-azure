## AFC multi-input entry and originals

Administrators enter up to 20 AFC records directly, review inline field errors, and attach an optional PDF to each saved record. An eligible record can be reopened from the AFC list. Excel paste appends rows to the draft. Retry uses the original batch or upload identity.

The runtime product is `f136ebcf3cb8e963e8c2359135e0d5bbefd1bced`. SQL 071 adds the procedure for linking an original to an active batch record and the view that identifies eligible records for the administrator list. The original must match the faculty and the uploading administrator. Existing permissions govern downloads. Apply SQL 071 before switching the University API, then publish Firebase Hosting from the successful main build.
